🚀 COMIENZA EN 3 PASOS
═══════════════════════════════════════════════════════════════════════════════

1️⃣ EDITA TUS DATOS
Abre: src/data/cv.ts

    Cambia:
    • hero.name → Tu nombre
    • hero.title → Tu título profesional
    • hero.description → Tu descripción
    • about → Tus párrafos de experiencia
    • skills → Tus habilidades
    • experience → Tu historial laboral
    • education → Tu educación

2️⃣ EJECUTA LOCALMENTE
Terminal:
$ npm install (solo la primera vez)
$ npm run dev

    Abre en navegador:
    → http://localhost:5173/curriculumVitae/

3️⃣ DESPLIEGA EN GITHUB PAGES
Actualiza package.json:
"homepage": "https://TU_USERNAME.github.io/curriculumVitae"

    Terminal:
    $ npm run deploy

    Tu sitio estará en:
    → https://TU_USERNAME.github.io/curriculumVitae/

🎨 TEMAS DISPONIBLES
═══════════════════════════════════════════════════════════════════════════════

Selecciona cualquiera de estos 3 temas con colores fríos:

🔵 BLUE TECH (Predeterminado)
• Color principal: Azul profesional (#0366d6)
• Fondo: Blanco
• Perfecto para: Presentaciones técnicas

⚪ SLATE MINIMAL
• Color principal: Gris pizarra (#475569)
• Fondo: Gris muy claro
• Perfecto para: Minimalista, corporativo

💚 EMERALD NIGHT
• Color principal: Verde esmeralda (#059669)
• Fondo: Azul oscuro
• Perfecto para: Moderno, contraste alto

Cambiar tema predeterminado:
→ Abre src/config/themes.ts
→ Busca: export const DEFAULT_THEME = 'blue-tech'
→ Cambia a: 'slate-minimal' o 'emerald-night'

O usa el selector flotante 🎨 en la esquina inferior derecha.

📞 SOPORTE RÁPIDO
═══════════════════════════════════════════════════════════════════════════════

❓ El sitio no se ve bien
→ Ctrl+Shift+R (limpiar caché)

❓ Error en la terminal
→ npx tsc --noEmit (verificar TypeScript)

❓ Build falla
→ rm -rf node_modules && npm install

❓ El tema no cambia
→ Abre DevTools → Application → Storage → localStorage
→ Elimina la clave "theme"
