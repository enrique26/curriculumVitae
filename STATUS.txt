🚀 INICIO RÁPIDO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. INSTALAR DEPENDENCIAS
   npm install

2. DESARROLLO LOCAL
   npm run dev
   → Acceso: http://localhost:5173/curriculumVitae/

3. PERSONALIZAR DATOS
   Edita: src/data/cv.ts
   - Nombre y título
   - Párrafos de experiencia
   - Skills
   - Experiencia laboral
   - Educación

4. CAMBIAR TEMA
   Edita: src/config/themes.ts
   export const DEFAULT_THEME = 'slate-minimal'
   
5. BUILD PARA PRODUCCIÓN
   npm run build

6. DESPLEGAR EN GITHUB PAGES
   npm run deploy
   → https://TU_USERNAME.github.io/curriculumVitae/
